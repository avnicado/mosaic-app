# Languages (English, Hebrew)

Mosaic's interface can be shown in English (the default) or Hebrew. The choice
is in Settings → Language, is saved under `m2:lang` (so it follows the person to
every device), and Hebrew turns the page right to left.

## How strings work

`src/i18n/index.js`. English is the source text and the lookup key:

```js
import { t, tp, loc } from '../../i18n/index.js';
t('New thread')                                   // "שרשור חדש" in Hebrew
t('Ends {date}', { date: fmt(ts) })                // placeholders in {braces}
t('{left} of {total} left', { left: <strong>3</strong>, total })  // values may be React nodes
tp(n, '{n} thread', '{n} threads')                 // English picks the form, then it's translated
new Date(ts).toLocaleDateString(loc(), { … })      // loc() is undefined in English, 'he-IL' in Hebrew
```

- Pass a plain string literal as the first argument (no template literals with
  `${…}`): the check script reads them.
- Call `t()` at render time, not at module load, so a language switch takes effect.
- Never translate what goes to a model (prompts, `engine/prompts.js`), what goes
  to the server, stored values, or content people or sources wrote (questions,
  notes, article titles, release notes).
- Hebrew lives in `src/i18n/he/*.js`, one file per area, keyed by the exact English.
- `npm run i18n-check` lists strings with no Hebrew, and placeholders that differ.

## Right to left

`<html dir="rtl" lang="he">` in Hebrew. CSS uses logical properties
(`margin-inline-start`, `inset-inline-end`, `text-align: start`,
`border-inline-start`), which are the same as before in English. Charts and
mandalas (SVG) stay left to right; numbers, code and links keep their own
direction. Directional icons (`arrow`, `back`) mirror. `src/i18n/rtl.css` holds
the Hebrew-only adjustments (fonts, letter-spacing on small labels).

Fonts: Fraunces, Instrument Sans and JetBrains Mono have no Hebrew. In Hebrew
the stacks add Frank Ruhl Libre (serif) and Heebo (sans, labels), loaded only
when Hebrew is on. Latin text still uses the original faces.
